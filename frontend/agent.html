Research Agent

Give the agent a research goal. A bounded worker gathers evidence from the records; a separate authority releases the answer or honestly declines.

Working over the corpus. Every result carries its scope and each shortlisted firm shows an explicit confidence.

The worker may only use a fixed set of read-only tools over the records; a separate reviewer — never the worker — authorizes or declines each answer, so nothing self-certifies.

Answers come only from what the records can prove. When the evidence is thin, the agent declines rather than guessing.
