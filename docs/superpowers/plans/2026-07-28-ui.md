# Customer-Facing UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A live Vercel-hosted single-page UI (served by the FastAPI app) that a non-programmer IR pro uses to query the dataset, rendering all 5 answer states clearly.

**Architecture:** `frontend/` static assets + FastAPI serving `/` and `/answer`, all running as one Vercel Python serverless function. Embedding model bundled in-repo.

**Tech Stack:** Vanilla HTML/CSS/JS, FastAPI, Vercel Python runtime, existing RAG backend.

## Global Constraints

- No field names / JSON / jargon shown to the user; readable message for all 5 states (answered/declined/no_match/empty/error).
- Frontend calls ONLY `POST /answer`.
- One page, YAGNI. Every visible word backed by real behaviour.
- Secrets via Vercel env vars, never committed.
